# ICAR (Indian Council of Agricultural Research) Knowledge Repository

## Source Information
- **Dataset / Source Name**: ICAR National Agricultural Research & Advisory Bulletins
- **Official Source**: [ICAR Central Research Institutes & Directorates](https://icar.org.in) (e.g. CICR Nagpur for Cotton, IIWBR Karnal for Wheat, NRCS Indore for Soybean)
- **Status**: Core expert advisories loaded locally for Cotton, Wheat, Soybean, and Rice. Complete research repository **REQUIRES MANUAL DOWNLOAD** from respective ICAR institute portals.

## Purpose
- Trusted, peer-reviewed agronomic science for crop cultivation, fertilizer ratios, integrated pest management (IPM), and crop disease treatments.
- Primary grounding source for Gemini LLM to eliminate hallucinated dosages.

## Expected File Format
- PDF manuals / Text guides containing: `Crop`, `Pest/Disease Name`, `Causal Organism`, `Economic Threshold Level (ETL)`, `Approved Bio-controls`, `Approved Chemical Controls (Formulation, Dosage per liter and per acre)`, `Waiting Period / Safety Precautions`.
