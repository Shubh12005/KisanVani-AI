# Other Verified Agricultural Sources

## Source Information
- **Dataset / Source Name**: CIBRC Chemical Guidelines & Government Schemes
- **Official Sources**:
  - [Central Insecticides Board & Registration Committee (CIBRC)](https://cibrc.nic.in)
  - [PM-KISAN Portal](https://pmkisan.gov.in)
  - [Pradhan Mantri Fasal Bima Yojana (PMFBY)](https://pmfby.gov.in)
- **Status**: Chemical safety rules and major welfare schemes loaded locally.

## Purpose
- Enforces strict safety rules on restricted chemicals, toxicity classifications (Red, Yellow, Blue, Green triangle labels), and government financial assistance policies.
