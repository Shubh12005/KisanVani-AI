# Krishi Vigyan Kendra (KVK) Regional Advisory Network

## Source Information
- **Dataset / Source Name**: KVK District-Level Farmer Advisory Bulletins
- **Official Source**: [ICAR-Agricultural Technology Application Research Institutes (ATARI)](https://kvk.icar.gov.in)
- **Status**: Regional Marathi and Hindi KVK bulletins loaded locally. Full district network archives (730+ KVKs) **REQUIRES MANUAL DOWNLOAD**.

## Purpose
- District-specific, vernacular advisories tailored to real-time ground conditions, regional soil types (e.g. Vidarbha black soil), and seasonal pest alerts.
- Provides native language context (Marathi, Hindi, Punjabi) for multilingual cross-lingual retrieval.

## Expected File Format
- Text bulletins containing: `KVK Name`, `District`, `State`, `Target Language (mr/hi/pa/en)`, `Weekly Pest/Nutrient Advisory`, `Specific Chemical & Non-Chemical Recommendations`.
