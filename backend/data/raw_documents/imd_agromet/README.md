# IMD (India Meteorological Department) Agromet Advisory Services

## Source Information
- **Dataset / Source Name**: Gramin Krishi Mausam Sewa (GKMS) Agrometeorological Bulletins
- **Official Source**: [IMD Agrimet Portal (agrimet.imd.gov.in)](https://agrimet.imd.gov.in)
- **Status**: Sample national Agromet advisories loaded locally. Daily district-wise weather bulletins **REQUIRE MANUAL DOWNLOAD**.

## Purpose
- Provides weather-forecast-linked agricultural advice (rainfall, relative humidity, heatwaves, frost forecasts) for timely pesticide sprays and irrigation scheduling.

## Expected File Format
- State / District agromet bulletin files containing: `Date`, `Rainfall Prediction`, `Temperature Max/Min`, `Crop-wise Actionable Recommendations`.
